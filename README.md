# Computer Vision

This repository contains my work for Lab Task 01 on computer vision and image processing using Python and OpenCV.

## Repository Contents

### Files

The `Files` folder contains the following Python program:

* **`images.py`** — Loads images from the `Images` folder using OpenCV, displays them in separate windows, and checks whether they were loaded successfully.

### Images

The `Images` folder contains two sample images used to test the Python program:

* **`image1.jpg`**
* **`image2.jpg`**

The images may contain photographs, objects, scenery, or other suitable visual content.

## Requirements

Install OpenCV using the following command:

```bash
pip install opencv-python
```

## Project Structure

```text
Computer Vision/
├── Files/
│   └── images.py
└── Images/
    ├── image1.jpg
    └── image2.jpg
```

## How to Run

Open a terminal in the `Files` folder and run:

```bash
python images.py
```

The program will load both images and display them in separate OpenCV windows. Press any key to close the image windows.
